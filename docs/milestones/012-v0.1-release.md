# M012 — v0.1 release

**Status:** Planned  
**Depends on:** M001-M011  
**Outcome:** First public Linux/macOS release with stable documented v0.1 contracts.

## Versioning/MSRV

- [ ] Choose and document formal v0.1 MSRV based on actual dependency/toolchain needs.
- [ ] Set package version `0.1.0`.
- [ ] Freeze repository format/schema versions for release.
- [ ] Verify migration behavior for any pre-release development formats that must be supported or explicitly declare them unsupported before v0.1.

## Documentation

- [ ] User manual matches implemented CLI exactly.
- [ ] README project status/quick-start is accurate.
- [ ] Gmail setup verified against current Google docs/UI.
- [ ] Linux Secret Service troubleshooting complete.
- [ ] macOS credential behavior documented.
- [ ] Security/threat model reviewed.
- [ ] Runtime skills reviewed against actual `help --json` schema.
- [ ] Public source/runtime repository distinction is clear.

## Release builds

- [ ] GitHub Actions or equivalent builds supported targets:
  - [ ] macOS arm64
  - [ ] macOS x86_64 if practical/supported
  - [ ] Linux x86_64
  - [ ] Linux arm64
- [ ] Produce checksums/signatures according to final release policy.
- [ ] Verify binaries embed matching runtime templates/skills.
- [ ] Smoke-test `init`, `connect` mock path, pull fake/mock path, offline triage, push fake/mock path.

## Release safety

- [ ] No telemetry.
- [ ] No secret test data committed.
- [ ] No real mailbox content in fixtures.
- [ ] Provider scope remains `gmail.modify` only.
- [ ] No send/permanent-delete capability accidentally present.
- [ ] `push --all-accounts` absent.
- [ ] Pull force override absent.

## Public project

- [ ] Confirm canonical GitHub repository URL and update Cargo metadata.
- [ ] Apache-2.0 license present.
- [ ] Tag `v0.1.0`.
- [ ] Publish GitHub Release binaries and release notes.

## Exit criteria

- [ ] A technical user can install, initialize a separate mail repository, configure Gmail OAuth from docs, connect, pull, triage offline manually or with a supported harness skill, review staged actions, and push safely.
